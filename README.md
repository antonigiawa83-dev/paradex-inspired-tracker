# Full-Stack Market Intelligence System

Sistem pemantauan pasar keuangan global yang mendukung 60+ aset secara real-time. 
Proyek ini mengintegrasikan analisis data backend menggunakan Python dan antarmuka visual interaktif berbasis TypeScript.

### Fitur Utama:
- **Multi-Asset Monitoring**: Forex, Metal, dan Cryptocurrency.
- **Technical Indicators**: Terintegrasi dengan Stochastic RSI dan VWAP.
- **Full-Stack Architecture**: Menggunakan TypeScript untuk dashboard dan Python untuk pemrosesan data.
- **Dockerized**: Siap dijalankan di lingkungan produksi mana pun.
